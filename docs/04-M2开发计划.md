## M2.1 可靠性修补（P0，0.5 天）

| 项 | 现状 | 要做的 | 验收 |
| --- | --- | --- | --- |
| Ctrl+C 清理 | `finally` 未必执行，可能留下 `lock` | 注册 SIGINT/SIGTERM：释放 lock、游标已逐页落盘、退出码 130 | 运行中 Ctrl+C，`lock` 被清理，重跑不报「已有进程」 |
| 游标键 | 只含标签/精确/类型/r18/ai/since/until | 加入 `sort`（以及未来影响结果集的参数），避免换排序后错误续跑 | 切换 `--sort` 后不会复用旧游标 |
| `--sort popular` | 非 Premium 实测退化为时间排序 | 检测 `is_premium=false` 时自动回退 `date_desc` 并警告；`--strict-sort` 时报错 | 非 Premium 加 `--sort popular` 输出警告且行为=date |
| ugoira mp4 | 只验证了 gif（模块级） | 用真实 ugoira 跑通 `--ugoira mp4`（ffmpeg libx264）；补 `--ugoira-width` 边界 | 生成的 mp4 可被 ffprobe 读取，帧数/时长正确 |
| 失败条目信息 | 只记 pid/stage/error | 记录 tag、bookmarks、artist、type、url、http_status、时间 | `failed.jsonl` 足够 retry 重建请求 |
| 部分文件 | `.part` 会在失败时清理 | 补：进程退出时清理残留 `.part`（启动扫描一次） | 无残留 `.part` |

## M2.2 `retry` 子命令（P0，0.5 天）

```text
ptdl retry -o <out> [--min-bookmarks N] [--jobs N] [--delay N] [--json]
```

- 读取 `<out>/.pixivdl/failed.jsonl`，按 pid 去重；
- 用 `api.illustDetail(pid)` 重新取元数据/图片 URL（不依赖失败时缓存）；
- 重新应用当前过滤条件（收藏数可能已变化；低于阈值则标记 `skipped_by_filter`）；
- 成功写 state、从失败清单移除（重写 failed.jsonl，原子替换）；
- 退出码：全部成功 0，仍有失败 1。

验收：断网制造 2 条失败 → 恢复网络 `ptdl retry` → 2 条成功、无重复文件；再跑一次 retry 不再处理。

## M2.3 覆盖核对与报告（P1，1 天）

### 数据结构

`<out>/.pixivdl/coverage.jsonl`（每行一个窗口）：

```json
{"tag":"オリジナル","day":"2025-01-01","desc":5010,"asc":5009,"boundaryOk":false,
 "webTotalLower":7957,"collected":10019,"status":"estimated_gap","note":"boundary gap 6.5h"}
```

状态：`complete`（未触顶或边界接上） / `estimated_gap`（触顶且边界未接上） / `unverified`（关闭核对或 Web 不可用）。

### 命令选项

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `--coverage-check <best-effort\|strict\|off>` | `best-effort` | strict：出现 `estimated_gap` 退出码 5；off：不做 Web 核对 |
| `--cookie <PHPSESSID>` | 无 | Web 核对/R-18 场景使用；没有则 Web total 只作下界 |

### 行为

1. 逐窗口（通常单日）记录 desc/asc 数量与边界时间戳是否接上；
2. `best-effort`：对触顶窗口发 1 次 Web `scd/ecd` 请求取 `total`（下界），只记录差异，不强行补；
3. 结束时打印：

```text
覆盖报告：窗口 128 个 | complete 126 | estimated_gap 2 | 校验下界差异最大 37 条
```

4. `--json` 汇总包含 coverage 统计；
5. 不把 `webTotalLower` 当等号（匿名 Web 不含 R-18，实测账号可见集合更大）。

### 明确不做（留 M3）

- Web 深翻页全量补漏（匿名 `p≥11` 被钳制；登录态是否放宽未验证）；
- 单日可见 >10,000 的自动补齐（非 Premium 无解）。

## M2.5 Premium 路径（P2，0.5 天 + 外部验证）

- 登录后读取 `is_premium`，在 doctor/启动日志中显示；
- `--server-bookmark-filter <auto|on|off>`（默认 auto）：
  - Premium → 搜索带 `bookmark_num_min/max`，结果仍本地复核；
  - 非 Premium → 忽略该参数并警告；
- `--sort popular`：Premium 时启用并可在「整页收藏数都低于阈值」时早停；
- 非 Premium 账号（当前 `demo-account`）下用单测断言参数不发送；行为验证需要你有 Premium 账号，届时跑一次 `coverage-lab`/小标签实测即可。
