```powershell
node scripts/verify-range.mjs --tag 西行寺幽々子 --since 2026-10-26 --until 2026-11-14 --out downloads-test-yuyuko
```

校验内容：

1. App API 枚举该区间的全部可见作品（含 R-18，账号可见口径），与已下载 pid 做集合差；
2. 单独统计 R-18 子集、收藏 >100 子集的完成率；
3. 取 Web Ajax 搜索同区间的匿名 `total`，对比「安全作品」数量；
4. 输出缺失清单（pid/画师/收藏/分级）。

## 3. 与 Web 端数量的差异（重要）

校验结果：

```
App API 可见: 210 条（R-18 68，收藏>100 45，安全口径 142）
Web 匿名 total: 110
已下载: 210 个作品 / 1262 个文件（R-18 68，收藏>100 45，失败 0）
缺失: 0 | 多余: 0
```

**下载数量与 App API 账号可见集合完全一致，但与 Web 匿名搜索的 110 不同。** 逐条分析原因如下：

| 差异来源 | 数量 | 说明 |
| --- | --- | --- |
| R-18（`x_restrict>0`） | 68 | 匿名 Web 搜索不返回；账号可见 |
| 轻度敏感（`sanity_level=4/6`，但 `x_restrict=0`） | 30（21+9） | 实测匿名 Web 搜索只返回 `sl=2` 的作品；sl=4/6 被匿名端过滤，详情页却可正常打开 |
| Web 搜索索引差异 | 2 | 2 个 `sl=2` 作品不在 Web 搜索结果里，但 `/ajax/illust/{id}` 详情可访问（索引/收录差异） |
| 合计 | 142（安全口径）+68（R-18）=210 | 与下载数一致 |

实测分布（同一区间）：

```
App API 安全口径 sl: {2:112, 4:21, 6:9}
Web 匿名搜索结果 sl: {2:110}
```

结论：

- 你的需求是「包含 R18 + 最近作品 + 收藏>100」——**当前工具按账号可见口径全部拿到，无缺漏**；
- 若把「与 Web 端相同」定义为**匿名 Web 搜索的 110 条**，则不同是预期行为（Web 匿名隐藏 R18 与轻度敏感，另有 2 条索引差异）；
- 要验证「登录态 Web 端」的数量，需要用浏览器 `PHPSESSID` 再取一次 Web total（关闭安全搜索/登录后），预计会接近 210。当前未提供 cookie，因此该项未验证。

- M1 主链路在真实任务（210 作品 / 1,262 文件 / 2.28 GB）上通过：命名、多页、ugoira→GIF、过滤、断点续跑、失败记录均正常；
