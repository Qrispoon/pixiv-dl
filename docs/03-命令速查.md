# ptdl 命令速查（M1 当前可用）

> 适用于当前仓库（M1 MVP）。执行前先确保代理环境变量已设置，二选一：
>
> ```powershell
> # 方式 A：环境变量（推荐）
> $env:HTTPS_PROXY = 'http://127.0.0.1:10090'
> $env:HTTP_PROXY  = 'http://127.0.0.1:10090'
> $env:NODE_USE_ENV_PROXY = '1'
>
> # 方式 B：在 ptdl.config.json 里写 "proxy": "http://127.0.0.1:10090"（CLI 会自动重入进程）
> ```
>
> 下文的 `ptdl` 等价于 `node bin/ptdl.mjs`（执行过 `npm link` 后可直接用 `ptdl`）。

---

## 1. 环境 / 登录 / 自检

| 命令 | 说明 |
| --- | --- |
| `ptdl --help` / `ptdl --version` | 查看帮助/版本（未 npm link 时用 `node bin/ptdl.mjs`） |
| `node bin/ptdl.mjs doctor` | 自检：代理、四域名、鉴权、搜索、图片、ugoira（转发给 `scripts/probe.mjs`） |
| `node bin/ptdl.mjs doctor --tag 初音ミク --rate-test` | 自检并做 5 次连续请求测限流 |
| `node bin/ptdl.mjs doctor --json` | 自检输出 JSON |
| `node scripts/login.mjs --open` | 浏览器登录（PKCE），token 保存到 `.secrets/` |
| `node scripts/login.mjs --cookie "PHPSESSID=…"` | 用浏览器会话 cookie 直接换 token（无需抓包） |
| `node scripts/login.mjs --code "pixiv://account/login?code=…"` | 手动粘贴 code / 回调 URL |
| `node scripts/login.mjs --check` | 验证本地 token 是否可用 |
| `node bin/ptdl.mjs login --check` | 同上（走子命令转发） |

## 2. 下载主命令

```text
node bin/ptdl.mjs download <标签...> [选项]
```

`download` 可省略：`node bin/ptdl.mjs -m 1000 初音ミク` 也等价。

### 2.1 选项一览

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `-o, --out <dir>` | `./downloads` | 输出根目录 |
| `-m, --min-bookmarks <n>` | `0` | 收藏数下限（含） |
| `--max-bookmarks <n>` | 无 | 收藏数上限（含） |
| `-n, --limit <n>` | 无 | 本次最多下载作品数 |
| `--max-pages <n>` | `200` | 每个扫描窗口最多请求页数（防失控） |
| `--since <YYYY-MM-DD>` | 无 | 起始发布日期 |
| `--until <YYYY-MM-DD>` | 今天 | 截止发布日期 |
| `--sort <date\|popular>` | `date` | `popular` 仅 Premium 有效（非 Premium 实测退化为时间排序） |
| `--exact` | 关 | 标签精确匹配（默认部分匹配） |
| `--and` | 关 | 多个标签合并成一次搜索（默认逐个搜索后按 pid 合并） |
| `--type <illust\|manga\|all>` | `all` | 作品类型过滤 |
| `--r18 <exclude\|include\|only>` | `exclude` | R-18 过滤（本地判断 `x_restrict`） |
| `--ai <exclude\|include\|only>` | `include` | AI 作品过滤 |
| `--ugoira <gif\|mp4\|zip\|skip>` | `gif` | 动图交付；`skip` 直接跳过动图 |
| `--ugoira-width <px>` | `540` | GIF/MP4 输出宽度（480–1080 常用） |
| `--keep-ugoira-zip` | 关 | 转码后同时保留原始 zip |
| `--name <模板>` | `{artist}-{id}-{bookmarks}` | 命名模板（见下） |
| `--by-tag` | 关 | 每个标签建一个子目录 |
| `--jobs <n>` | `2` | 下载并发（作品级） |
| `--delay <秒>` | `2` | App API 请求最小间隔（实测 0.5s 易 429） |
| `--retries <n>` | `5` | 单请求重试次数（429 会冷却 65s 再试） |
| `--timeout <秒>` | `60` | 单请求超时 |
| `--proxy <url>` | 环境变量 | HTTP(S) 代理；CLI 会重入进程使代理生效 |
| `--dry-run` | 关 | 只打印候选，不下载、不写状态 |
| `--force` | 关 | 忽略已完成记录重新下载 |
| `--no-resume` | 关 | 忽略扫描游标，从头扫描 |
| `--json` | 关 | 结束时输出 JSON 汇总（dry-run 也支持） |
| `-v, --verbose` | 关 | 打印扫描/HTTP 细节 |

命名模板可用字段：`{artist}` `{account}` `{artist_id}` `{id}` `{bookmarks}` `{title}` `{date}` `{page}` `{ext}`。
多页自动加 `_p0/_p1…`；动图自动加 `_ugoira`。

### 2.2 常用示例

```powershell
# 预览：不下载
node bin/ptdl.mjs download 初音ミク -m 1000 --since 2024-01-01 --limit 10 --dry-run

# 下载到指定目录
node bin/ptdl.mjs download 初音ミク -m 1000 -o "D:\pixiv\miku"

# 多标签（默认 OR：逐个搜索按 pid 去重）
node bin/ptdl.mjs download 初音ミク アークナイツ -m 5000 -o "D:\pixiv\mix"

# 多标签 AND（合并成一次搜索）
node bin/ptdl.mjs download 初音ミク オリジナル --and -m 1000

# 只扫最近一个月、限制扫描深度
node bin/ptdl.mjs download 女の子 --since 2026-10-14 -m 10000 --max-pages 20

# 动图
node bin/ptdl.mjs download 初音ミク --ugoira gif --ugoira-width 720
node bin/ptdl.mjs download 初音ミク --ugoira mp4
node bin/ptdl.mjs download 初音ミク --ugoira zip --keep-ugoira-zip
node bin/ptdl.mjs download 初音ミク --ugoira skip

# 过滤
node bin/ptdl.mjs download 初音ミク --r18 include --ai exclude
node bin/ptdl.mjs download 初音ミク --type manga

# 按标签建子目录 + 自定义命名
node bin/ptdl.mjs download 初音ミク アークナイツ --by-tag --name "{artist}-{id}-{bookmarks}-{title}"

# 断点续跑 / 强制重下
node bin/ptdl.mjs download 初音ミク -m 1000 -o "D:\pixiv\miku"      # 再次运行会跳过已完成
node bin/ptdl.mjs download 初音ミク -m 1000 --no-resume --force

# 内联代理（不设环境变量）
node bin/ptdl.mjs download 初音ミク -m 1000 --proxy http://127.0.0.1:10090

# 机器可读输出
node bin/ptdl.mjs download 初音ミク -m 1000 --json
```

## 2.3 失败重试（M2.2）

```powershell
ptdl retry -o "D:\pixiv\miku"              # 重试 failed.jsonl 里的全部失败项
ptdl retry -o "D:\pixiv\miku" -m 1000      # 按当前收藏数重新过滤，低于 1000 的直接放弃
ptdl retry -o "D:\pixiv\miku" --dry-run     # 只看会重试哪些
ptdl retry -o "D:\pixiv\miku" --jobs 3 --json
```

- 按 pid 重新 `illust/detail` 取元数据，再走正常过滤/下载；
- 已完成的跳过并移出失败清单；低于当前门槛的标记「过滤跳过」；
- 成功/仍失败会原子重写 `failed.jsonl`；退出码 0=全部清空，1=仍有剩余。

## 2.4 运行安全（M2.1）

- Ctrl+C / SIGTERM：释放 `lock`、退出码 130（游标已逐页保存，重跑续跑）；
- 下次启动自动清理残留 `.part` 与 `.pixivdl/tmp`；
- 上次进程被强杀留下的 stale lock：检测 pid 已不存在时自动接管；
- 非 Premium 用 `--sort popular` 会警告并自动回退 `date`；
- ugoira `mp4` 已实测（libx264；高度自动取偶数）。

## 3. 配置文件

复制 [`ptdl.config.example.json`](../ptdl.config.example.json) 为：

- 当前目录 `ptdl.config.json`，或
- `%APPDATA%\pixiv-tag-dl\config.json`

优先级：CLI 参数 > 环境变量 > `./ptdl.config.json` > `%APPDATA%` 配置 > 默认值。
自定义路径：`node bin/ptdl.mjs download ... --config D:\conf\ptdl.json`。

主要键：`proxy`、`out`、`minBookmarks`、`maxBookmarks`、`ugoira`（默认 `"gif"`）、`ugoiraWidth`、`keepUgoiraZip`、`name`、`byTag`、`jobs`、`delay`、`retries`、`timeout`、`r18`、`ai`、`sort`。
token 也可放配置 `refreshToken`，或环境变量 `PIXIV_REFRESH_TOKEN`。

## 6. 输出与状态

```
<out>/
├─ 画师-pid-收藏数.png
├─ 画师-pid-收藏数_p1.png
├─ 画师-pid-收藏数_ugoira.gif
└─ .pixivdl/
   ├─ state.jsonl     已完成作品（重跑跳过）
   ├─ cursors.json    扫描进度（断点续跑）
   ├─ failed.jsonl    失败记录
   └─ lock            防并发（删除可强制解锁）
```

退出码：`0` 成功；`1` 有失败项；`2` 参数/配置错误；`3` 鉴权失败（需重新登录）。
